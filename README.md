# Menged Asset Management System

A modern inventory and asset management system developed for managing organizational assets, consumables, and inventory operations.

## Overview

The Menged Asset Management System provides a centralized platform for tracking inventory items, assets, consumables, categories, and stock levels. The application is designed to improve inventory visibility, streamline asset tracking, and support efficient inventory management processes.

## Features

### Dashboard
- Inventory overview
- Asset status monitoring
- Low stock alerts
- Quick actions
- Inventory analytics

### Inventory Management
- View all inventory items
- Add new items
- Edit existing items
- Delete items
- Search and filter inventory
- Pagination support

### Asset Management
- Track company assets
- Asset assignment information
- Serial number tracking
- Purchase date records
- Condition monitoring
- Asset status management

### Consumables Management
- Consumable inventory tracking
- Quantity monitoring
- Minimum stock level tracking
- Stock status indicators

### Categories
- Category-based organization
- Category statistics
- Asset and consumable breakdown
- Category drill-down view
- Searchable categories

### User Experience
- Responsive interface
- Persistent navigation sidebar
- Routing with React Router
- Interactive modals
- Clean dashboard layout

## Technology Stack

- React
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React Icons
